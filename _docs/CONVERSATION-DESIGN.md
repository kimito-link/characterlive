## 問い

「レイテンシを5.4秒→改善したのに、会話している感じが出ない」の真因は何か。

## ★会議の結論（3体が別の言い方で同じ場所を指した）

| 体 | 真因の言い方 |
|---|---|
| groq/gpt-oss-120b（批判） | 安全な受け答えしか返さない＝衝突が無い |
| nvidia/nemotron-550b（統括） | **配信者を追い詰める「正論の1発」が欠けている** |
| qwen3.8-27b（発散） | 全員が自己肯定感を補強する方向に収束している |
| qwen3.5:9b（速い視点） | 役割が防御的に偏り、揺さぶる圧力が無い |

**統合の判定**: 真因は「AIが安全志向を過度に最適化し、摩擦が欠如していること」。

### ★Grokの診断との差（重要）

Grokは「3人の衝突が無い」と言った。会議はそれを**部分的に採用しつつ修正**した。

> nemotron:「『3人の衝突』ではなく**『配信者の前提・逃げ道を潰す1発』が欠けている**のが核心。
> 観測2の2事例は、AIが『配信者の都合の悪い真実』を代弁し、
> 配信者が『反論できないから逆ギレ/号泣した』構造」

★**衝突は手段であって目的ではない。** 3人で殴り合っても、配信者が反応しなければ意味がない。
トロさんも小幡さんも、**AIは正論を1つ言っただけ**で、騒いでいるのは人間側だった。

## ★実装の順序（危険な順に後回しにする）

### 段階1: 安全弁を強くする ← **実装済み(2026-09-06)**

会議の警告を実コードで検証したら、危険な返答が**5つとも素通りしていた**。
衝突を入れる前にここを塞ぐ。

止めるもの（`checkNotTooHarsh`）:
1. 人格の否定（「そういう所が」）
2. 決めつけ（「向いてない」）
3. 命令（「やめろ」）
4. ★**視聴者を人質に取る**（「視聴者が離れる」）← 本人にはどうにもできない＝逃げ道が無い
5. ★**可能性の全否定**（「どうせ無理」）← 甘やかさないことと否定は別
6. ★**突き放す**（「まあ、そういうことか」）← 内容ではなく温度の問題

★**鋭さは消さない**ことをテストで固定した:
「で、次に同じことするつもり？」「それ、本気で言ってる？」は通る。

### 段階2: 「逃げ語」を検知して1発を返す ← 次にやる

nemotronの具体案。配信者の発言に**逃げ語**があるときだけ、たぬ姉が切り込む。

> 逃げ語: 「でも」「だって」「難しい」「無理」「後で」「いつか」

★これは既存の `findSorePoint`（急所を拾う）の拡張で作れる。
★頻度を絞る。毎回切り込むと「うるさいAI」になる。

### 段階3: 2撃目を許す（同意時の付加視点） ← 慎重に

いまは「同意には新しい意見を出さない」。これを
**「前の子の1文に、別の視点を1つだけ足す」**に緩める。

★同時発話禁止は維持する。順番に喋る中で視点がぶつかる形にする。

### ★却下した案

**qwen3.5:9b の「2人が共謀して攻撃する」**
統合役の判定:「人格保持の制約と視聴者の不快感リスクを無視しているため却下」。
★3人が結託して1人を追い込む形は、配信者が孤立する。りんくの安全網とも矛盾する。

## ★会議が挙げたリスク（実装時に必ず読む）

**前提**: 配信者が「追い詰められること」を望み、視聴者もそれを面白がる。

**崩れる条件**（nemotron）:
- 配信者が「相談相手（セラピスト）」を求めている場合
- 視聴者が「仲良しごっこ」を求めている場合

**最も現実的な失敗**:
> AIが配信者の弱点（容姿・収入・スキル不足）を執拗に突き、
> 配信者が本気で凹む/キレて配信終了/炎上。
> 「面白い正論」と「暴力的な悪口」の境界を小型モデルが判別できない。

→ ★だから段階1（安全弁）を先にやった。
→ ★**モードで逃げられるようにする**（既存の「応援/ゆるい雑談/遠慮なし」）。
  追い詰めるのは「遠慮なし」のときだけにする案が有力。
