# inbox — 外から来た調査結果の受け皿

- Grok の日課タスク（X の実投稿を集める）の出力を、`grok-YYYY-MM-DD.md` としてここに置く。
- 毎朝の Claude 日課タスク（`characterlive-daily-companion-research`）が未処理のファイルを読み、
  `_docs/RESEARCH-LEDGER.md` に同じ書式で取り込み、末尾に「取り込み済み: ファイル名」を書く。
- ★個人情報（人名・メール・金額）は貼る前に伏せる。このリポは public。
- 取り込み済みのファイルは消さなくてよい（台帳側に「取り込み済み」が残るので二重処理されない）。
