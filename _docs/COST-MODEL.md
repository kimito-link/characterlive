# 黒字の式（/api/chat・Claude Fable 5.1）

> 2026-10-19 作成。正本: `ai-generic-rules/docs/policies/COST_SAFETY_POLICY.md` §A-4 / §6。
> ★**数字はすべて提案**（未決定）。為替は 1ドル＝150円で換算。
> 実装: `src/lib/chatCostGuard.js`（見積り・予約）／`api/chat.js`（入口）。数字を変えるときはコードの定数と一緒に直す。

## 前提（いまの状態）

- 本番は `ANTHROPIC_API_KEY` が**未設定**（2026-10-19 に `GET /api/chat` が `hasKey:false`）。今は1円も燃えない。
- このPRで、鍵を入れても **KV（カウンタ）が無ければ POST は常に拒否**される。鍵を入れるのは KV を用意した後。
- 既定の頭脳は端末内蔵の無料AI（Gemini Nano・原価ゼロ）。Fable はクラウド頭脳を選んだときだけ使う。

## 1回の原価 c（見積りの式）

| 項目 | 値 | 出典 |
|---|---|---|
| 単価 | 入力 $10 / 出力 $50（1M トークンあたり） | Claude Fable 5.1 の公表値（2026-10） |
| 入力トークン | （system の字数 ＋ user の字数）× 2 | 日本語は概ね1字≒1トークン。予約は多めに数える側に倒して ×2 |
| 出力トークン | 1,024（`CLOUD_MAX_TOKENS` 全部使った扱い） | 思考トークンも出力に含まれるため |
| 典型（system 約700字・user 2,000字） | 約 $0.11 ≈ **17円** | `estimateCallMilli(900, 2000)` = 110 ミリドル |
| 最大（system 1,500字・user 8,000字） | 約 $0.24 ≈ **36円** | `MAX_CALL_MILLI` = 242 ミリドル |

★1回の発話で最大2回呼ぶことがある（オウム返しの言い直し）。2回目も同じく予約してから呼ぶ。

## §A-4 の表

| 項目 | 内容（提案） |
|---|---|
| 原価 c | Fable 1回 典型 約17円・最大 約36円（上の式） |
| 無料枠 F | **匿名の全体予算のみ**（人を数えられないため・§A-3）。1日 $0.50（約75円）＝典型の約4回分（2026-10-20 の裁定で小さくした）。IP ごとに1日20回 |
| 有料 P/N | 未設計（ログイン・決済が無い）。たとえば 980円／20回 なら 粗利 ＝ 980 − 20×17 − 決済手数料約35 ≈ **605円** |
| 損益分岐の課金率 r* | ログイン利用者に月5回の無料枠を付けた場合: r* ＝ 5×17 ÷ 605 ≈ **14%**（★方針の目安 2% を大きく超える） |
| 匿名の全体予算 | 1日 約75円（`CHAT_DAILY_BUDGET_MILLI` 既定 500） |
| 最悪の日の損 | 約75円／日（全体予算の上限）。月 約2,250円 |

### この表から読めること

- **Fable の原価は1回十数円〜数十円**で、文章生成の例（0.3円）の50〜100倍。ログイン利用者に無料枠を付けると r* が 14% になり、方針の「2%以下」を満たさない。
- 満たす形は2つしかない: ①Fable は無料枠を付けず有料購入の後に置く（無料の人は内蔵AI＝原価ゼロ）、②クラウド頭脳の原価を下げる（安いモデル・出力を短く。下の「選択肢」）。どちらにするかは未決定。
- それまでは**匿名の全体予算（上の表の1日約75円）だけが無料枠**で、使い切ったら「本日のクラウド会話枠は終了しました」と出して、決め打ちの台詞に落ちる（黙らない）。

## 選択肢: クラウド頭脳の既定モデルを Haiku 4.5 にする（★本人判断・このPRではモデルは変えない）

Claude Haiku 4.5（`claude-haiku-4-5`）は 入力 $1 / 出力 $5（1M トークンあたり）で、Fable の10分の1。同じ見積りの式で数えると:

| 項目 | Fable 5.1（いま） | Haiku 4.5（選択肢） |
|---|---|---|
| 原価 c（典型） | 約17円 | 約1.6円 |
| 原価 c（最大） | 約36円 | 約3.6円 |
| ログイン利用者の無料枠 F | 付けられない（月5回で r* ≈ 14%） | **月10回**（10×1.6 ≈ 16円/人/月） |
| 粗利（980円／20回の例） | 約605円 | 980 − 20×1.6 − 約35 ≈ 約913円 |
| 損益分岐の課金率 r* | 約14% | 16 ÷ 913 ≈ **約1.8%**（目安 2% 以下を満たす） |

- つまり **1回1〜2円で、月10回の無料枠を付けても黒字の形になる**。代わりに返事の質が Fable より下がる可能性がある（雑談の質は未測定）。
- 切り替えるときに直す所（未着手）: `src/lib/charaCloudRequest.js` の `CLOUD_MODEL`、`output_config.effort`（Haiku 4.5 は effort を受け付けない）、`fallbacks` と `betas`（断られたときに別のモデルで続ける機能は Fable 向け）。見積りの単価 `PRICE_*`（`src/lib/chatCostGuard.js`）も一緒に変える。
- ★どちらにするかは本人が決める。

## 最悪の日の計算（§6）

```
最悪の1日の損 = 匿名の全体予算 = $0.50 ≈ 75円
最悪の1か月   = 75円 × 30 ≈ 2,250円
```

- **L0（提供元の上限）**: この製品専用の Anthropic キーを作り、ワークスペースの月の支出上限を **$15（約2,250円）**＝最悪の1か月ぶん にする（提案）。
  KV やコードが壊れても、そこで止まる。
- L1: `PAID_CALLS_DISABLED=1`（Vercel の環境変数を入れるだけ。デプロイ不要）。
- L2: `CHAT_DAILY_BUDGET_MILLI`（全体の日次予算）。L4: `CHAT_IP_DAILY_CALLS`（IP ごと）。

## 鍵を入れる前のチェックリスト

1. Vercel に KV（Upstash 連携）を足し、`KV_REST_API_URL` / `KV_REST_API_TOKEN` が入ったことを確かめる
2. Anthropic でこの製品専用のキーを作り、ワークスペースの支出上限（L0）を設定する
3. `CHAT_DAILY_BUDGET_MILLI` は既定（500）のままで始める（上げるのは実データを見てから）
4. `ANTHROPIC_API_KEY` を入れる → `GET /api/chat` が `ready:true` になることを見る
5. 上限に達したとき「本日のクラウド会話枠は終了しました」と出て、決め打ちの台詞に落ちることを見る
